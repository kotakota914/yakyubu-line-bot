# yakyubu-line-bot

野球部専用のLINE公式アカウント。下部メニューを「大会メンバー / 試合日程 / 練習日程 / 連絡」の4タブに分け、
これまで大会ごとに作っていた専用グループLINEを1つの公式アカウントに集約する。

## できること

- タブ切り替え式のリッチメニュー(4タブ)
- 大会ごとにメンバーを登録・閲覧(大会名で切り替え管理)
- 試合日程・練習日程の登録・一覧・削除
- 連絡事項(練習メニュー変更、集合時間の変更など)の投稿・一覧
- 登録・編集は監督/マネージャーなど「管理者登録」した人のみ。閲覧は全部員OK
- (任意)毎朝7:00に当日の試合・練習予定を自動送信

## ファイル構成

```
├── index.js               # Webhookサーバー本体(コマンド処理の中心)
├── db.js                  # JSONファイルDBアクセス層(ネイティブ依存なし)
├── parser.js              # メッセージのコマンド解析
├── setup-richmenu.js      # リッチメニュー登録スクリプト
├── generate_richmenu.py   # リッチメニュー画像生成スクリプト(Pillow使用)
├── richmenu-assets/       # リッチメニュー画像(PNG、生成済み)
├── package.json
├── .env.example
└── db.json                # 初回起動時に自動生成される(データ本体)
```

## セットアップ手順

### 1. LINE Developersでチャネルを作る

1. https://developers.line.biz/console/ にログイン(LINEアカウントでOK)
2. プロバイダーを新規作成(部活動用など好きな名前)
3. チャネルを作成する際は **必ず「Messaging API」を選択**する
   (「LINEログイン」チャネルではWebhookやリッチメニューが使えないので注意)
4. チャネル作成後、「Messaging API設定」タブを開く
   - ページ下部で **Webhookの利用** を「オン」にする
   - **チャネルアクセストークン(長期)** を発行してコピー
   - 「チャネル基本設定」タブの **チャネルシークレット** もコピー

### 2. プロジェクトの準備

```bash
cd yakyubu-line-bot
npm install
cp .env.example .env
```

`.env` を開いて、以下を書き換える。

```
LINE_CHANNEL_ACCESS_TOKEN=（手順1でコピーした長期トークン）
LINE_CHANNEL_SECRET=（手順1でコピーしたチャネルシークレット）
ADMIN_SECRET=（監督・マネージャーだけに伝える合言葉。好きな文字列でOK）
```

### 3. ローカルで起動して動作確認(ngrok使用)

```bash
npm start
```

別のターミナルで ngrok を使ってインターネットに公開する:

```bash
ngrok http 3000
```

表示された `https://xxxx.ngrok-free.app` を使い、LINE Developersコンソールの
「Messaging API設定」→「Webhook URL」に

```
https://xxxx.ngrok-free.app/webhook
```

を設定して保存し、「検証」ボタンで成功することを確認する。

### 4. リッチメニュー(4タブ)を登録する

画像は `richmenu-assets/` にすでに生成済みなので、そのまま登録できる。
デザインを変えたい場合は `generate_richmenu.py` を編集して再生成する(要 `pip install Pillow`)。

```bash
node setup-richmenu.js
```

実行すると自動で

1. 前回登録分のリッチメニュー・エイリアスを削除(再実行しても安全)
2. 4つのリッチメニューを作成
3. 画像をアップロード
4. `members` / `games` / `practices` / `contact` のエイリアスを作成(タブ切り替えの実体)
5. 「大会メンバー」タブをデフォルト表示に設定

まで行われる。完了後、LINEアプリでこの公式アカウントのトーク画面を開き直すと反映される。

### 5. 自分を管理者として登録する

LINEでこの公式アカウントに向けて

```
管理者登録 (.envに設定したADMIN_SECRET)
```

と送る。「✅ 管理者として登録しました。」と返ってくれば成功。これで登録・削除系のコマンドが使えるようになる。

### 6. 本番運用にする(Renderなどへのデプロイ)

ngrokは起動している間しか使えないので、部活で継続運用するにはどこかにデプロイする。
[Render](https://render.com) の無料プランなら、ネイティブ依存のないこのプロジェクトはそのまま動く。

1. このプロジェクトをGitHubリポジトリにpushする(`.env` は `.gitignore` 済みなので上がらない)
2. Renderで「New Web Service」を作成し、リポジトリを選択
3. Build Command: `npm install` / Start Command: `npm start`
4. 環境変数タブで `.env` の中身と同じ値を設定(`LINE_CHANNEL_ACCESS_TOKEN` など)
5. デプロイ完了後に発行されるURL(`https://xxxx.onrender.com/webhook`)を
   LINE DevelopersのWebhook URLに設定し直す
6. `node setup-richmenu.js` はローカルから実行すればOK(LINEのAPIに直接登録するだけなので、
   デプロイ先のサーバーで実行する必要はない)

## 主なコマンド一覧

「ヘルプ」と送るといつでも一覧を確認できる。各タブにも「使い方」ボタンがある。

| 分類 | 誰でも見られる | 管理者のみ |
|---|---|---|
| 大会メンバー | `大会一覧` / `大会メンバー [大会名]` | `大会登録 大会名` / `大会メンバー登録 大会名`(2行目以降に1人ずつ) / `大会メンバー削除 大会名 名前` / `大会削除 大会名` |
| 試合日程 | `試合一覧` | `試合登録 対戦相手 日付 時間 場所` / `試合削除 番号` |
| 練習日程 | `練習一覧` | `練習登録 日付 時間 場所 内容` / `練習削除 番号` |
| 連絡 | `連絡一覧` | `連絡 本文`(複数行OK) |

## 注意点・今後の拡張候補

- 日付は `7/20` のような `月/日` 形式。今日から30日以上前の日付は「来年」の日付とみなして並び替えるため、
  過去の記録を大量に貯めていく用途には向かない(あくまで直近の予定管理向け)。
- `ENABLE_DAILY_REMINDER=true` にすると毎朝7時に当日予定を全員へブロードキャストできるが、
  LINE公式アカウントの無料メッセージ数を消費するので部員数に応じて検討すること。
- 大会が増えてきたら「大会削除」で過去のものを整理できる。
- 将来的に、大会メンバーをLIFF(LINEのミニウェブアプリ)でカレンダーのように見せたり、
  試合結果・スコアを記録する機能を足すこともできる。
